# IPv4-адреса и специальные диапазоны

## Частные адреса

RFC 1918 выделяет три диапазона, которые организации могут использовать во внутренних сетях без глобальной регистрации:

| Диапазон | Префикс | Маска |
| --- | --- | --- |
| `10.0.0.0–10.255.255.255` | `10.0.0.0/8` | `255.0.0.0` |
| `172.16.0.0–172.31.255.255` | `172.16.0.0/12` | `255.240.0.0` |
| `192.168.0.0–192.168.255.255` | `192.168.0.0/16` | `255.255.0.0` |

Маршрутизаторы публичного Интернета не должны распространять маршруты к этим диапазонам. Для обычного выхода IPv4-хостов с частными адресами во внешнюю сеть часто применяется [[NAT]]. Частный адрес не означает, что хост автоматически защищён: доступ определяется маршрутизацией и правилами фильтрации.

## Другие важные специальные адреса

| Диапазон или адрес | Назначение |
| --- | --- |
| `0.0.0.0` | Неопределённый адрес; в зависимости от контекста также обозначает привязку сервиса ко всем локальным интерфейсам. |
| `127.0.0.0/8` | Loopback. Наиболее известный адрес — `127.0.0.1`. |
| `169.254.0.0/16` | Link-local IPv4; может назначаться автоматически при отсутствии другой конфигурации. |
| `255.255.255.255` | Ограниченный широковещательный адрес текущего канала. |

Полный перечень специальных IPv4-регистров ведёт IANA: <https://www.iana.org/assignments/iana-ipv4-special-registry/iana-ipv4-special-registry.xhtml>.
