# Основы кибербезопасности

Этот раздел формирует техническую базу, без которой результаты сканеров и атакующих инструментов легко интерпретировать неправильно.

## Порядок изучения

1. [[Сети/README|Компьютерные сети]] — адресация, порты, маршрутизация, NAT и удалённый доступ.
2. [[Linux/README|Linux]] — пользователи, права, конфигурация, сервисы, журналы и файловые системы.
3. [[Windows/README|Windows]] — базовая работа с Windows и клиентами передачи файлов.
4. [[Web и HTTP/README|Web и HTTP]] — устройство веб-сервера и его конфигурации.
5. [[Контейнеры и инфраструктура/README|Контейнеры и инфраструктура]] — Docker и практическая работа с контейнерами.
6. [[Контрольные вопросы]] — самопроверка по всему фундаментальному блоку.

## Результат обучения

После раздела специалист должен уметь:

- объяснить путь пакета между хостами и назначение основных сетевых уровней;
- различать адрес, порт, протокол и сетевой сервис;
- безопасно работать с пользователями, файлами, пакетами и службами Linux;
- читать базовую конфигурацию Apache, Nginx и Docker;
- диагностировать проблему до применения средств оценки безопасности.

Материалы сканирования, API-тестирования, hardening и лабораторных атак перенесены в профильные разделы, чтобы не смешивать фундамент с методами проверки.
