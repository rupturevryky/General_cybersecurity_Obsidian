# Защитная настройка

- [[iptables]] — фильтрация пакетов и учебные правила.
- [[Fail2ban]] — реакция на повторяющиеся события по журналам.

Перед изменением firewall обеспечьте консольный доступ и проверенный путь отката. Fail2ban не заменяет MFA, ключевую аутентификацию, ограничение экспозиции и своевременные обновления.
