2. [[Инструменты перечисления]]

Автоматизированное перечисление формирует кандидатов, а не доказанные пути. Каждый результат необходимо подтвердить вручную: субъект, разрешение, исполняемый контекст, условие эксплуатации, достижимое влияние и защитная мера.

Не выполняйте найденный бинарный файл или exploit только потому, что инструмент отметил его как возможный путь.
