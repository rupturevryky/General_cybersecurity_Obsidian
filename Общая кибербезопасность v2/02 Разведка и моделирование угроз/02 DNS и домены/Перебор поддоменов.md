> [!note] Исправленный цикл
> Конструкция `for name in $(cat file)` ломает строки на пробелах и выполняет лишний `cat`. Используйте построчное чтение и явный тест результата.

```bash
while IFS= read -r name; do
  host "${name}.example.test" | grep 'has address'
done < dns.txt
```

> [!note] Статус материала
> Исходный конспект сохранён, но команды, версии, зависимости и внешние ссылки необходимо сверять с официальной документацией перед практикой.

# Перебор поддоменов

> [!warning] Активная техника
> Перебор создаёт DNS-запросы и не относится к пассивной разведке. Используйте только домены в scope, ограничивайте интенсивность и сохраняйте использованный словарь.

Организации используют поддомены для приложений, сред разработки, удалённого доступа и служебных систем. Перебор по словарю помогает дополнить известный перечень, но результат необходимо проверить и сопоставить с владельцем актива.

### Брутфорс субдоменов

Суть этого метода состоит в том, чтобы подобрать имя поддомена. Воспользоваться можно программой **host**. Введем команду:
```
host ns3.alg*******ge.com
```
Если в ответ получим строку `ns3.alg*******ge.com has address 205***.***.11`, то такой поддомен существует.

Вручную перебирать имена — нудное занятие. Поэтому мы будем автоматизировать. Создадим файл со списком имен поддоменов. Можно найти готовый на просторах интернета, но для демонстрации я создал простейший файл с содержимым `mail dns ftp file vpn test dev prod voip firewall` и называл его `dns`. Теперь для запуска перебора имен необходимо написать мини-скрипт:
```
while IFS= read -r name; do host "${name}.example.test" | grep 'has address'; done < dns.txt
```

### DNSMap

[DNSMap](https://github.com/makefu/dnsmap "DNSMap"). Он делает почти те же действия, что описаны выше. В нем уже встроен словарь, но можно использовать и свой. Для запуска перебора необходимо набрать:
```
dnsmap alg*******ge.com
```
Процесс это небыстрый. У меня он занял (для выбранного домена) 1555 секунд, но и результат выдал неплохой — нашел 18 поддоменов.
