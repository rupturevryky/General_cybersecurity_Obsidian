# Разведка и моделирование угроз

Разведка создаёт проверяемую карту активов и связей до активного тестирования. Результатом должен быть не список команд, а набор наблюдений с источником, временем получения, уровнем уверенности и разрешённым следующим действием.

## Порядок изучения

1. [[01 Методология разведки/Процесс разведки|Процесс разведки]]
2. [[01 Методология разведки/Карточка актива|Карточка актива]]
3. `02 DNS и домены` — DNS-записи, поддомены и контролируемая проверка переноса зоны.
4. `03 Метаданные и документы` — извлечение сведений из опубликованных документов.
5. `04 OSINT по идентификаторам` — email, публичные идентификаторы и никнеймы.
6. `05 Фингерпринтинг` — сопоставление технических признаков.
7. [[06 Инструменты/README|Инструменты разведки]]

## Граница с оценкой защищённости

- Пассивный сбор использует уже опубликованные сведения и не отправляет проверочные запросы целевой системе.
- Активное обнаружение взаимодействует с системами и требует согласованного scope, ограничений интенсивности и журналирования.
- Поиск уязвимостей и подтверждение риска относятся к [[03 Оценка защищённости/README|оценке защищённости]].
