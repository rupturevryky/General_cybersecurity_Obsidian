# Итоговый проект младшего специалиста

## Формат

Итоговая работа собирается из назначенных преподавателем лабораторий внешних платформ. Набор должен охватывать разведку или обнаружение поверхности, веб-приложение, Windows/Linux либо сетевой анализ. Одна лаборатория не обязана моделировать всю организацию.

## Этапы

1. Зафиксировать платформу, модули, идентификаторы заданий, правила и scope каждого активного экземпляра.
2. Для задания по инфраструктуре построить реестр выданных активов и модель доверительных границ.
3. Провести только разрешённое условиями обнаружение поверхности.
4. Для приложения выбрать релевантные проверки вместо универсального сканирования.
5. Верифицировать минимум одну находку и аргументированно разобрать один неподтверждённый сигнал либо false positive.
6. Проанализировать предоставленные платформой журналы или PCAP; если их нет, перечислить необходимые источники телеметрии.
7. Подготовить объединённый технический отчёт и краткое резюме для условного владельца.
8. Описать retest по предлагаемому исправлению; выполнить его только тогда, когда это предусмотрено самой лабораторией.

## Условие успешного завершения

Все выводы воспроизводимы в рамках соответствующей лаборатории, действия не выходят за выданные цели, доказательства не раскрывают флаги и токены, а рекомендации связаны с первопричиной и имеют проверяемый критерий исправления.
