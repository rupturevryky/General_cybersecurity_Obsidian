# Критерии оценки практической работы

| Критерий | Недостаточно | Достаточно |
| --- | --- | --- |
| Scope | Не указано задание либо проверялись посторонние цели | Указаны платформа, модуль, экземпляр, выданные цели и ограничения |
| Воспроизводимость | Только отметка `Solved` или скриншоты | Есть версия задания, инструменты, действия и ожидаемые результаты без раскрытия секретов |
| Понимание | Пересказ вывода инструмента | Объяснены протокол, поток данных или первопричина |
| Безопасность | Правила платформы и границы экземпляра проигнорированы | Соблюдены scope, rate limit, stop conditions и завершение сессии |
| Доказательство | Непроверенный alert | Минимально подтверждённая гипотеза либо обоснованный false positive |
| Защита | Общая рекомендация | Конкретное исправление и способ retest |
| Работа с данными | Опубликованы флаги, токены или реальные данные | Секреты задания скрыты, доказательства отредактированы, правила публикации соблюдены |
