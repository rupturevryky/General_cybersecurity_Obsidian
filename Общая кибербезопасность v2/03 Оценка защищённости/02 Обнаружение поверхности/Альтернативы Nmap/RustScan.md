> [!note] Проверенная установка
> Официальное руководство рекомендует фиксированный стабильный Docker-образ `2.1.1`; тег `latest` считается экспериментальным. RustScan передаёт найденные порты в Nmap, поэтому параметры после `--` относятся уже к Nmap.

```bash
docker pull rustscan/rustscan:2.1.1
docker run --rm -it --name rustscan rustscan/rustscan:2.1.1 --help
docker run --rm -it --name rustscan rustscan/rustscan:2.1.1 \
  --addresses <LAB_TARGET> -- -sV
```

При запуске контейнера адрес `127.0.0.1` означает сам контейнер, а не хост. Скорость и число одновременно открытых файлов зависят от ОС и сети; рекламные значения времени не являются гарантией.

> [!warning] Разрешённая среда
> Исходный конспект сохранён. В рамках курса команды применяйте только к назначенной цели внешней учебной платформы и в пределах её правил; версии, зависимости и флаги сверяйте с первичной документацией.

[RustScan](https://github.com/RustScan/RustScan) - Современный сканер портов. Превращает 17-минутное сканирование Nmap в 19 секунд.

   Возможности инструмента:

• Сканирует все 65k портов за 3 секунды.

• Полная поддержка скриптового движка. Автоматически передавайте результаты в Nmap, или используйте наши скрипты (или напишите свои собственные).

• Адаптивное обучение. RustScan улучшается по мере того, как вы его используете. Здесь нет раздутого машинного обучения, только базовая математика.

• Автоматически направляет порты в Nmap.
