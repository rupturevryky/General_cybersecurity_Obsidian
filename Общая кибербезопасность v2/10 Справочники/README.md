# Справочники

- [[Каталог инструментов]] — исходный перечень инструментов со ссылками на тематические заметки.
- `Команды` — короткие операционные шпаргалки, включая [[Команды/Временный HTTP-сервер|временный HTTP-сервер]].
- [[Внешние источники]] — материалы вне репозитория.
- [[Оценка внешнего источника]] — чек-лист перед включением материала в курс.
- [[Внешние источники/Web CTF Cheatsheet|Web CTF Cheatsheet]] — сохранённая внешняя ссылка, оцениваемая по чек-листу источника.

Справочник не задаёт методологию и не является разрешением на выполнение команды. Учебный контекст находится в разделах `01–09`.
