# Временный HTTP-сервер

Быстрый сервер удобен для передачи файлов в лаборатории. По умолчанию он может открыть содержимое текущего каталога всем узлам, имеющим сетевой доступ: запускайте его из специально подготовленной папки и останавливайте сразу после использования.
php
```bash
php -S {ip}:{port}
```
python
```bash
python3 -m http.server {port}
```
ngrok
```bash
// в одном терминале сначала поднимается сервер
php -S 127.0.0.1:1234
```

```bash
// в другом ngrok
ngrok http 9001
```
