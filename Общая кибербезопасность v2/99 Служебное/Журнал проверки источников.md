# Журнал проверки источников

Проверены 53 заметки, ранее имевшие статус `migrated-needs-source-review`. Основные базовые линии:

- OWASP Web Security Testing Guide Latest и OWASP Cheat Sheet Series — Web, API, аутентификация и инъекции;
- RFC 9700 / BCP 240 — безопасность OAuth 2.0;
- RFC 8725 — безопасная реализация JWT;
- WHATWG Fetch — same-origin policy и CORS;
- RFC 6455 — WebSocket;
- Android Developers Security и OWASP MASVS/MASTG — Android;
- NIST SP 800-153 — безопасность WLAN;
- Microsoft Learn — Windows CLI, CIM/WMI и системное администрирование;
- MITRE ATT&CK/CWE — классификация лабораторных техник и ошибок реализации;
- официальная документация Nmap и производителей — обзорные инструментальные материалы.

## Существенные исправления

- Implicit Flow переведён в исторический сценарий; современной базовой линией назначен Authorization Code с PKCE.
- Для JWT запрещено доверять входному `alg`; `alg: none` описан только как отрицательный тест ошибочного verifier.
- WMIC и `Get-WmiObject` помечены legacy; актуальные примеры переведены на CIM cmdlets.
- Для Wi‑Fi добавлена базовая линия WPA3 / WPA2 AES-CCMP, отключение WPS и сегментация.
- Android-раздел получил безопасный учебный стек и запрет случайных «хакерских APK».
- Исторические payload-фрагменты сохранены, но отделены от рекомендаций для реальных систем.

Каждая проверенная заметка содержит `last_reviewed`, `verified_against` и статус `source-review-complete`.
