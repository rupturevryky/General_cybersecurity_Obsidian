# Аутентификация и сессии

- [[Уязвимости аутентификации]] — идентификация, вход, MFA и восстановление доступа.
- [[CSRF]] — целостность действий в cookie-based сессиях.
- [[Безопасность JWT]] — структура JOSE-токенов, проверка подписи и доверие к ключам.
- [[OAuth 2.0 и OpenID Connect]] — делегированная авторизация и федеративная идентификация.

Аутентификация отвечает на вопрос «кто пользователь», авторизация — «что ему разрешено», а управление сессией поддерживает это утверждение между запросами. Проверять их следует раздельно.
