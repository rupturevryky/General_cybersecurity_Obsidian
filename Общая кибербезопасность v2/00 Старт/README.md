# Общая кибербезопасность v2

Учебная база для подготовки начинающих специалистов по этичной кибербезопасности.

## Как начать

1. Прочитайте [[Этика и правовые границы]].
2. Откройте [[Учебный маршрут]].
3. Используйте [[Карта разделов]] для навигации по предметным областям.
4. Выполняйте практические действия только в запущенных для вашего аккаунта заданиях внешних учебных платформ и строго в пределах их правил.
5. Для технического состояния миграции и оставшихся ограничений смотрите [[99 Служебное/Итоговый аудит v2|Итоговый аудит v2]].

## Принципы базы

- От фундаментальных знаний к анализу защищённости и специализациям.
- Разделение теории, методологии, инструментов и практических заданий.
- Обязательная фиксация области разрешённого тестирования.
- Сохранение исходных материалов и прозрачный учёт перемещений.
- Приоритет понимания причин уязвимости и способов защиты над механическим запуском инструментов.

## Статус миграции

Миграция и содержательная переработка завершены. Текущий [[99 Служебное/Реестр миграции|реестр миграции]] содержит 657 строк: 649 файлов актуального v1 и 8 файлов исходного раздела `Android безопасность`. Для разделённых и объединённых материалов в `CurrentPaths` указаны все актуальные пути. Одобренные владельцем удаления и добавление новой CORS-схемы отражены в служебных журналах.
