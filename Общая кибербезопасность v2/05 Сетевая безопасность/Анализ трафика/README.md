# Анализ сетевого трафика

- [[tcpdump]] — захват и первичная фильтрация пакетов.

## Методика

1. Сформулируйте вопрос: какой хост, протокол или событие требуется подтвердить.
2. Выберите интерфейс и минимальный capture filter.
3. Ограничьте объём, время и размер файла.
4. Зафиксируйте временную зону и синхронизацию часов.
5. Отделите наблюдение в пакете от вывода о причине события.
6. Храните PCAP как потенциально чувствительные данные.

Перехват трафика допустим только в сети, где получено соответствующее разрешение: пакеты могут содержать токены, персональные данные и учётные сведения.
