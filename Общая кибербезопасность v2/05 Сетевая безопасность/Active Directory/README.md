## Учебный подход

Сначала опишите лес, домены, контроллеры, доверия, группы, сервисные учётные записи и административные пути. Затем формулируйте гипотезу о конкретном доверительном отношении. Массовый сбор, подбор паролей и дамп секретов требуют отдельного разрешения и изолированной лаборатории.

Административные основы Windows находятся в [[06 Безопасность систем/Windows/Исследование и администрирование Windows]].
