> [!warning] Протокольная атака
> Устанавливайте mitm6 изолированно через pipx и запускайте только в отдельном учебном сегменте: атака влияет на IPv6/DNS.

> [!warning] Разрешённая среда
> Исходный конспект сохранён. В рамках курса команды применяйте только к назначенной цели внешней учебной платформы и в пределах её правил; версии, зависимости и флаги сверяйте с первичной документацией.

Популярный инструмент атаки на IPv6.
**Установка**:
```
pipx install mitm6
mitm6 --help
```
Иcпользование:
```
mitm6 -d {domain} 
```
Этого уже достаточно, чтобы встать посередине, представившись DNS сервером.

В то же время можно развернуть SMB сервер через [[impacket#Передать файл через SMB (развернуть SMB сервер)|impacet smbserver]] и красть аутентификационные данные пользователя, пытающегося подключиться к настоящей файловой шаре, но переходящего на подставную.
