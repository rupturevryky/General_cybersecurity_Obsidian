# Временный HTTP-сервер

Быстрый сервер удобен для передачи несекретных файлов внутри назначенной лаборатории внешней платформы. По умолчанию он может открыть содержимое каталога всем узлам, имеющим сетевой доступ: используйте отдельную папку, привязку к нужному интерфейсу и остановите процесс сразу после передачи.

## Python

```bash
python3 -m http.server {port} --bind 127.0.0.1 --directory {directory}
```

## PHP

```bash
php -S 127.0.0.1:{port} -t {directory}
```

## Публичный туннель

Ngrok публикует локальный сервис в интернете. В курсе он не требуется по умолчанию; используйте его только при прямом разрешении задания и никогда не публикуйте каталог с ключами, токенами или персональными данными.

```bash
# Терминал 1
php -S 127.0.0.1:1234

# Терминал 2 — тот же локальный порт
ngrok http 1234
```

## Проверка

```bash
curl -I http://127.0.0.1:{port}/
```
