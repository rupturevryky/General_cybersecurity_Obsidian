# FreeRDP: подключение к RDP

FreeRDP — клиент Remote Desktop Protocol. Используйте только выданный учебной платформой узел и учётные данные.

Проверьте имя бинарного файла и параметры установленной версии:

```bash
xfreerdp /version
xfreerdp /help
```

В некоторых дистрибутивах FreeRDP 3 клиент называется `xfreerdp3`. Базовое подключение без передачи пароля в командной строке:

```bash
xfreerdp /v:{host} /u:{user} /d:{domain}
```

Ключ `/d` нужен только для доменной учётной записи. Параметр `/p:{password}` удобен, но раскрывает пароль в history и списке процессов, поэтому предпочтителен интерактивный запрос.

В исходной заметке был пример pass-the-hash:

```text
xfreerdp /d:{domain} /u:{user} /v:{host} /pth:{NT-hash}
```

Это не обычная административная авторизация. Использование `/pth` допустимо только тогда, когда оно прямо требуется назначенной лабораторией внешней платформы; NT hash является секретом и не должен попадать в отчёт.
