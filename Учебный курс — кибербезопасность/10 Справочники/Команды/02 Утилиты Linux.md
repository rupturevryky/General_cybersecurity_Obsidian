## Справка 

`tldr` - утилита, выводящая простую справку по другим утилитам
``` 
tldr ls
```

cheat.sh - интернет ресурс, выводящий простую справку по утилитам
```
curl cheat.sh/ls
```

explainshell.com - интернет ресурс, разбирающий команду по частям. 
``` 
tar -czvf backup.tar.gz /home/username
```
- Explainshell покажет, что каждый флаг в команде означает. Теперь ты понимаешь, что `-c` — это создание архива, `-z` — сжатие, `-v` — вывод на экран процесса, а `-f` — имя файла.

## Поиск в файле

**`xdg-open`** открывает файл или URL в приложении по умолчанию. Не используйте его для неизвестного объекта: обработчик может выполнить активное содержимое.

**`steghide`** показывает сведения о поддерживаемом контейнере и извлекает ранее встроенные данные; он не является универсальным детектором стеганографии.
> ``` 
> steghide --info image.jpg
> steghide extract -sf image.jpg
> ```

**`ltrace`** перехватывает вызовы динамических библиотек исследуемого процесса. Это динамический анализ: неизвестный файл не запускают на основной системе.

### AWS
Существует саб-домин - **s3**. Это облачное хранилище для вещей в контейнерах. Корзины **AWS S3** имеют различные сценарии использования, включая резервное копирование и хранение, хостинг мультимедиа, доставку программного обеспечения, статический веб-сайт и тд. Файлы, хранящиеся в корзине Amazon S3, называются объектами S3.
**`awscli`** позволяет взаимодействовать с этой корзиной.
```
aws configure # первоначальная настройка. Можно установить значения temp.
```
Мы можем перечислить все корзины S3, размещенные на сервере, с помощью команды ls:
```
aws --endpoint-url http://s3.example.test s3 ls
```
Мы также можем использовать команду ls для перечисления объектов и общих префиксов в указанном бакете.
```
aws --endpoint-url http://s3.example.test s3 ls s3://lab-bucket
```
В исходной заметке предлагалась загрузка reverse shell в доступный на запись bucket. Это опасная проверка с изменением данных. В курсе выполняйте загрузку только безвредного тестового файла и лишь тогда, когда назначенная лаборатория прямо требует проверки записи; после задания удалите объект штатным способом платформы.
### WGET
GNU Wget сохраняет файл параметром `-O`:
```
wget -O output.bin https://example.test/file.bin
```

В PowerShell используется другая команда: `Invoke-WebRequest -Uri https://example.test/file.bin -OutFile output.bin`.

## Encrypt

Base64 — кодирование, а не шифрование. Кодировать файл: `base64 input.bin`; декодировать файл: `base64 --decode input.txt > output.bin`. Для строки используйте `printf '%s' 'SGVsbG8=' | base64 --decode`.

## PDF
Добавить вложение в новый PDF:
``` 
qpdf --empty --add-attachment note.txt --mimetype=text/plain -- output.pdf
```

Просмотреть ключи вложений и извлечь конкретное вложение:
```
qpdf input.pdf --list-attachments
qpdf input.pdf --show-attachment=note.txt > extracted-note.txt
```
##### Открыть PDF
```
evince file.pdf
```

## ZIP

Создать архив:
``` 
zip -r -9 <ИМЯ_АРХИВА>.zip <ФАЙЛЫ>
```
> `-r` — архивировать рекурсивно
> -9 — степень сжатия от 1 до 9.

Чтобы запаролить архив, используем ключ `-e`:
```
zip -e -r -9 <ИМЯ_АРХИВА>.zip <ФАЙЛЫ>
```

Пароль вводится интерактивно. Традиционное ZIP-шифрование может быть слабым; для чувствительных данных используйте утверждённый организацией формат и способ передачи ключа.

Распаковать:
``` 
unzip <ИМЯ_АРХИВА>.zip
```

Посмотреть содержимое без распаковки:
```
unzip -l <ИМЯ_АРХИВА>.zip
```

Для получения более детальной информации во время разархивирования:
``` 
unzip -v <ИМЯ_АРХИВА>.zip
```

Проверка целостности архива:
```
unzip -t archive.zip
```

Чтобы открыть `zip` по `паролю` и` shasum-е`, при `sha-256` == `307744fa0ae574756157a4607e307492141fdf1f000f6289eab4a8741729469c`
```shell
echo -n "307744fa0ae574756157a4607e307492141fdf1f000f6289eab4a8741729469c  name.zip" | sha256sum -c
```
Подбор утилиты для открытия по паролю:
```shell
unzip -P "password" name.zip
```
```shell
7z x -ppassword name.zip
```

## TAR

**Tar** - сам не может сжимать файлы, поэтому назвать его архиватором нельзя, однако он может закидывать файлы в один, поэтому для удобства всё таки будем его так называть.

Для того, чтобы архивировать файлы, нам нужно использовать следующую команду с такими ключами:
```
tar -cf <ИМЯ_АРХИВА>.tar <ФАЙЛЫ>
```
> `-c` - создать новый архив и записать в него файлы, -f - выводит результат в файл

Разархировать:
``` 
tar -xvf <ИМЯ_АРХИВА>.tar
```
> `-x` - разархировать
> `-f` - выводит результат в файл.

Посмотреть содержимое:
``` 
tar -tf <ИМЯ_АРХИВА>.tar
```

Но бывает и такие ситуации что мы можем забыть что-то, тогда в архив можно добавить файл.
```
tar -rf <ИМЯ_АРХИВА>.tar <ФАЙЛЫ>
```

Создать архив с сжатием. Используется gzip так как он самый популярный:
```
tar -zcf <ИМЯ_АРХИВА>.tar.gz <ФАЙЛЫ>
```
Для разархивации мы можем использовать тот же ключ `-x`:
```
tar -xf <ИМЯ_АРХИВА>.tar.gz
```
