# Social-Engineer Toolkit

> [!warning] Только исторический обзор
> Не запускайте рассылки, credential harvesting и payload-функции самостоятельно. В курсе инструмент рассматривается для понимания возможностей и защитных артефактов; активное применение допустимо только внутри прямо назначенного задания внешней платформы.

GitHub - [The Social-Engineer Toolkit (SET)](https://github.com/trustedsec/social-engineer-toolkit)

Это набор инструментов для социальной инженерии, написанный специалистом в области кибербезопасности Дэвидом Кеннеди, предназначенный для выполнения сложных атак против человеческих слабостей. Такие атаки известны как "социальная инженерия".

Исторически интерфейс запускался от root следующей командой:  
```
sudo setoolkit
```

В исходной заметке далее выбирались пункты `Social-Engineering Attacks` → `Mass Mailer Attack`, одиночный или групповой адресат, шаблон, тема и способ доставки. Эта последовательность сохранена как описание интерфейса, но не является упражнением курса.
