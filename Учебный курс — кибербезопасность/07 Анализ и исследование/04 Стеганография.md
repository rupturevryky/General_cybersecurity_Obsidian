# Стеганография

Стеганография — методы сокрытия самого факта передачи или хранения информации. В отличие от криптографии, которая скрывает содержание, стеганография пытается скрыть наличие сообщения; подходы могут применяться совместно.

Для чтения и представления данных в 16-ричном формате можно использовать сайт [HexEd.it](https://hexed.it/).
## Инструменты

> [!note] Ограничение
> Наличие скрытых данных сначала подтверждается воспроизводимым анализом. Инструменты и форматы требуют проверки на безопасных тестовых файлах.

## Outguess
Outguess - консольная утилита, но скрывать данные может только в изображениях.
Установка: 
```
sudo apt-get install outguess
```
Сокрытие: 
```
outguess -k "password" -d <message> <container_input> <container_output>
```
Пример:
```
outguess -k "password" -d msg.txt empty_cont.jpg fulled_cont.jpg
```
