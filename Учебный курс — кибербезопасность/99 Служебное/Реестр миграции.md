# Реестр миграции

Полный машиночитаемый реестр находится в файле [[Учебный курс — кибербезопасность/99 Служебное/Реестр миграции.csv|Реестр миграции]].

Для каждого из 665 исходных файлов записаны:

- исходный относительный путь;
- первоначальный путь после переноса в учебный курс;
- один или несколько актуальных путей после содержательной переработки (`CurrentPaths`);
- размер в байтах;
- SHA-256 исходного содержимого.

Сразу после копирования файлы были повторно прочитаны из новой структуры: 657 из 657 файлов папки `Кибербезопасность` и 8 из 8 файлов папки `Android безопасность` существовали и совпадали с исходниками по SHA-256.

Последующие исправления внутренних ссылок и содержательная редактура намеренно изменяют хеш рабочей копии. Исходный хеш в CSV остаётся контрольной точкой, позволяющей проверить сохранность и восстановить происхождение материала.
