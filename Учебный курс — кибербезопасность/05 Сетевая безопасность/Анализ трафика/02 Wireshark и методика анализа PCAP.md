# Wireshark и методика анализа PCAP

Wireshark разбирает протоколы и помогает связывать пакеты в потоки. До анализа сохраните исходный PCAP, работайте с копией и учитывайте, что файл может содержать токены, пароли, персональные данные и передаваемые документы.

## Capture и display filters

Capture filter ограничивает данные во время захвата и использует синтаксис BPF, например `host 192.0.2.10 and port 443`. Display filter применяется после захвата, например `ip.addr == 192.0.2.10 && tcp.port == 443`. Эти синтаксисы нельзя взаимозаменять.

## Алгоритм анализа

1. Зафиксируйте источник, время, интерфейс и цель исследования.
2. Посмотрите статистику endpoints, conversations и protocol hierarchy.
3. Постройте временную линию: DNS → установление TCP → TLS или прикладной протокол.
4. Найдите ошибки, повторные передачи, reset, необычные объёмы и новые назначения.
5. Используйте Follow Stream для контекста, но проверяйте исходные пакеты.
6. Сохраните фильтр, номера кадров и вывод как воспроизводимое доказательство.

## Полезные display filters

```text
dns
tcp.flags.syn == 1 && tcp.flags.ack == 0
http.request
tls.handshake.type == 1
tcp.analysis.retransmission
```

Отсутствие пакета в захвате не доказывает отсутствие события: могли быть выбраны неверный интерфейс, точка наблюдения, capture filter или момент времени.

## Внешняя практика

Используйте PCAP-задания TryHackMe, Hack The Box Academy или Malware-Traffic-Analysis.net; не перехватывайте чужой трафик.
