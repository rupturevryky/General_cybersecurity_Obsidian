# Практика

Практика курса выполняется на сторонних учебных платформах: PortSwigger Web Security Academy, Hack The Box и аналогичных сервисах, явно предоставляющих лабораторные цели. Курс не предполагает развёртывание собственного стенда. Завершённый статус платформы сам по себе не подтверждает понимание: учащийся должен объяснить гипотезу, действия, доказательства и защиту.
