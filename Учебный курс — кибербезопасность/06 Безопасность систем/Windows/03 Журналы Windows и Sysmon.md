# Журналы Windows и Sysmon

Windows Event Log хранит каналы System, Security, Application и журналы отдельных компонентов. Event ID имеет смысл только вместе с provider, версией ОС, полями и политикой аудита.

## Важные категории

- входы и ошибки входа;
- создание процесса и командная строка при разрешённой политике;
- изменение учётных записей, групп и политик;
- установка службы и задания планировщика;
- PowerShell Script Block Logging;
- события Defender и firewall;
- доступ к критичным объектам, если включён соответствующий аудит.

Sysmon дополняет штатный аудит подробной телеметрией процессов, сетевых соединений, драйверов и изменений файлов. Он не анализирует события сам: качество зависит от конфигурации и правил SIEM/EDR.

## Принципы

- централизованно пересылать события и защищать права изменения конфигурации;
- синхронизировать время;
- не включать максимальный аудит без оценки объёма;
- хранить исходное событие, а не только текст alert;
- проверять детектирование безопасной симуляцией.

## На собеседовании

Объясните различия Windows Event Log, Sysmon, Windows Event Forwarding, SIEM и EDR.
