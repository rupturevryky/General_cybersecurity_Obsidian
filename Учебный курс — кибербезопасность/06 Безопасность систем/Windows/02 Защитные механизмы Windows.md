# Защитные механизмы Windows

## Идентификация и привилегии

Access token содержит SID пользователя и групп, privileges и уровень целостности. UAC разделяет обычные и повышенные операции, но не является границей безопасности против уже работающего администратора. ACL объекта определяет, какие SID имеют конкретные права.

## Ключевые механизмы

- Microsoft Defender Antivirus предотвращает и обнаруживает вредоносную активность;
- Attack Surface Reduction rules ограничивают типовые опасные поведения;
- Windows Defender Firewall фильтрует входящие и исходящие соединения по профилям;
- BitLocker защищает данные выключенного устройства, но не заменяет контроль доступа работающей ОС;
- Credential Guard изолирует часть секретов с помощью virtualisation-based security;
- AppLocker и Windows Defender Application Control ограничивают запускаемый код;
- LAPS управляет уникальными локальными административными паролями.

## Приоритет настройки

Поддерживаемая версия ОС, обновления, отсутствие постоянной локальной админской работы, MFA для административных путей, уникальные локальные пароли, ограниченный RDP/WinRM, firewall, Defender и централизованные события.

Настройку проверяют на пилотной группе: жёсткая политика контроля приложений или ASR без аудита совместимости может остановить рабочие процессы.

## На собеседовании

Объясните, от каких угроз защищает BitLocker и почему он почти не помогает после входа злоумышленника в разблокированную систему.
