# Реестр, политики и автозагрузка

> [!abstract] Результат
> Ученик понимает структуру реестра, различает машинную и пользовательскую область, умеет безопасно читать настройки и связывать их с политикой и запуском программ.

## Что такое реестр

Реестр — иерархическая база конфигурации. Она содержит hives, keys и values. Значение имеет имя, тип и данные. Не вся конфигурация Windows находится в реестре, и не каждое найденное значение активно.

Основные логические ветви:

- `HKLM` — компьютер и установленное ПО;
- `HKCU` — текущий пользователь;
- `HKU` — загруженные профили пользователей;
- `HKCR` — объединённое представление ассоциаций и COM-классов;
- `HKCC` — текущий hardware profile.

Файлы hives находятся в системных каталогах и профилях, но редактировать их как обычные файлы нельзя.

## Типы значений

Часто встречаются `REG_SZ`, `REG_EXPAND_SZ`, `REG_DWORD`, `REG_QWORD`, `REG_MULTI_SZ` и `REG_BINARY`. Для `REG_EXPAND_SZ` переменные окружения разворачиваются потребителем. Число `0` или `1` не имеет универсального смысла без документации конкретного параметра.

```powershell
Get-ChildItem HKLM:\SOFTWARE
Get-ItemProperty 'HKLM:\SOFTWARE\Microsoft\Windows NT\CurrentVersion'
Get-ItemPropertyValue -Path 'HKLM:\Path' -Name ValueName
```

## 32- и 64-битные представления

WOW64 может предоставлять 32-битным приложениям отдельное представление некоторых областей реестра. Поэтому две утилиты разной архитектуры способны видеть разные значения. При расследовании фиксируют архитектуру процесса и способ чтения.

## Политики

Local Group Policy и доменные GPO задают управляемую конфигурацию компьютера и пользователя. Итог зависит от области, приоритета и применения политики. Ручное изменение значения, управляемого GPO, может быть перезаписано.

```powershell
gpresult /r
gpresult /h .\gpresult.html
```

Отчёт может содержать чувствительные сведения о домене и группах.

## Распространённые точки запуска

- Run и RunOnce в HKCU/HKLM;
- Startup folders;
- параметры служб;
- shell и userinit;
- file associations и protocol handlers;
- scheduled tasks;
- browser extensions;
- WMI permanent event subscriptions.

Это не список «вредоносных ключей»: штатное ПО использует те же механизмы. Оценивают путь, подпись, владельца, время, источник установки и поведение.

## Безопасное изменение

До изменения экспортируют конкретный ключ, фиксируют ACL и знают способ восстановления. Экспорт всего реестра не заменяет резервную копию системы.

```powershell
reg.exe export 'HKLM\Path' .\backup.reg
Get-Acl 'Registry::HKEY_LOCAL_MACHINE\Path'
```

На внешней платформе изменяйте только ключи из задания. В рабочей среде правка политики или автозапуска требует change control.

## Рабочий сценарий

После входа пользователя запускается неизвестная программа. Составьте порядок проверки Run keys, Startup folders, задач и журналов, не удаляя артефакт до фиксации.
