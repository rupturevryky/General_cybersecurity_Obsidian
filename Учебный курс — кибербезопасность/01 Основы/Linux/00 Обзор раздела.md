# Основы Linux

Linux — семейство операционных систем на основе ядра Linux. **Ядро** управляет процессором, памятью, устройствами и изоляцией процессов. Дистрибутив, например Ubuntu, Debian или Fedora, добавляет системные утилиты, менеджер пакетов, конфигурацию и набор программ.

## Что нужно знать до первой команды

- **Терминал** — программа с текстовым интерфейсом ввода и вывода.
- **Оболочка, или shell** — интерпретатор команд; часто используется Bash.
- **Команда** — запускаемая программа или встроенная функция shell.
- **Процесс** — выполняющийся экземпляр программы со своим PID, памятью и правами.
- **Пользователь** определяет, от чьего имени работает процесс и какие действия ему разрешены.
- **root** — административная учётная запись с UID `0`; `sudo` запускает отдельную команду с повышенными правами согласно политике.
- **Файл** — именованный объект файловой системы; каталог хранит имена и ссылки на объекты.
- **Абсолютный путь** начинается с `/`, относительный вычисляется от текущего каталога.

Минимальные команды навигации:

```bash
pwd                 # текущий каталог
ls -la              # содержимое и скрытые имена
cd /var/log         # перейти по абсолютному пути
cd ..               # перейти в родительский каталог
file имя            # определить тип содержимого
less файл           # безопасно просмотреть текст
man команда         # открыть локальную документацию
команда --help      # краткая справка
```

Shell разделяет команду и аргументы пробелами. Кавычки сохраняют пробелы внутри одного аргумента. Конструкция `>` перезаписывает файл выводом команды, `>>` добавляет, а `|` передаёт стандартный вывод следующей команде. Перед запуском незнакомой команды нужно понять каждый аргумент и область изменений.

## Основные каталоги

| Путь | Назначение |
| --- | --- |
| `/` | корень единого дерева файлов |
| `/home` | домашние каталоги обычных пользователей |
| `/root` | домашний каталог пользователя root |
| `/etc` | системная конфигурация |
| `/var` | изменяемые данные: журналы, очереди, кэши |
| `/tmp` | временные файлы; правила очистки зависят от системы |
| `/usr` | основная часть установленных программ и библиотек |
| `/proc`, `/sys` | виртуальные представления состояния ядра и устройств |

Linux чувствителен к регистру: `Report.txt` и `report.txt` — разные имена. Расширение файла не определяет его тип так строго, как это часто воспринимается в Windows.
