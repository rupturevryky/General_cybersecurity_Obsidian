# Shell, поиск и обработка текста

Shell разбирает строку, выполняет подстановки и перенаправления, затем запускает программу. Для аналитика это средство быстро сузить большой объём данных, но неверное экранирование или запуск неизвестного текста как команды создают риск.

## Потоки, конвейеры и коды возврата

У процесса есть стандартный ввод `stdin` (0), вывод `stdout` (1) и поток ошибок `stderr` (2). Конвейер `|` передаёт stdout одной команды на stdin другой.

```bash
command >out.txt 2>errors.txt
command >>out.txt 2>&1
journalctl -u ssh --since today | grep -i 'failed'
```

`>` перезаписывает файл, `>>` дописывает. Код возврата показывает `$?`. В Bash `set -o pipefail` заставляет конвейер считаться неуспешным, если ошиблась не только последняя команда.

## Кавычки и подстановки

- одинарные кавычки сохраняют текст буквально;
- двойные разрешают `$variable` и `$(command)`;
- некавыченная переменная может разбиться на слова и раскрыть шаблоны;
- `--` обычно завершает список параметров и защищает имя, начинающееся с `-`.

```bash
printf '%s\n' "$value"
grep -- "$pattern" file
```

Не передавайте недоверенный ввод в `eval`, `bash -c` или составную командную строку. Предпочитайте массив аргументов и инструменты с явными параметрами.

## Поиск файлов и содержимого

```bash
find /etc -xdev -type f -mtime -2 -ls 2>/dev/null
find / -xdev -type f -perm -4000 -ls 2>/dev/null
grep -RIn --exclude-dir=.git 'PermitRootLogin' /etc/ssh
rg -n 'password|token|secret' ./project
```

`find` проверяет метаданные файлов; `grep` и `rg` — содержимое. `-xdev` не переходит на другие файловые системы. Найденный SUID-файл не является уязвимостью сам по себе: проверяют владельца, происхождение пакета, версию и допустимость по baseline.

## Полезная обработка данных

```bash
cut -d: -f1,3,7 /etc/passwd
awk -F: '$3 == 0 {print $1, $7}' /etc/passwd
sort addresses.txt | uniq -c | sort -nr
sed -n '1,20p' file
xargs -0 command < names.bin
```

`awk` обрабатывает записи и поля, `cut` извлекает простые столбцы, `sort | uniq -c` считает повторения. Для имён файлов безопаснее NUL-разделитель: `find ... -print0` вместе с `xargs -0`. Перед массовым действием сначала выведите найденные объекты без изменения.

## Архивы, хеши и метаданные

```bash
file sample
stat sample
sha256sum sample
tar -tf archive.tar
```

Хеш подтверждает совпадение байтов, но не безопасность файла. Перед распаковкой недоверенного архива просмотрите список путей и выполняйте анализ только в разрешённой изолированной среде внешней платформы.
