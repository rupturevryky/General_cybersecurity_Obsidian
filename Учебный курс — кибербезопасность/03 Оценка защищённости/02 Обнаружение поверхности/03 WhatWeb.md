# WhatWeb

> [!note] Проверка установки и синтаксиса

```bash
whatweb --version
whatweb --help
whatweb https://example.test
whatweb http://192.0.2.10:8080
```

Фигурные скобки в старых примерах ниже обозначают заполнитель, а не часть команды. Используйте только адреса из разрешённого scope.

> [!note] Статус материала
> Исходный конспект сохранён, но команды, версии, зависимости и внешние ссылки необходимо сверять с официальной документацией перед практикой.

WhatWeb сопоставляет HTTP-ответы с plugin-сигнатурами и формирует fingerprint технологий. Результат может основываться на заголовке, cookie, HTML, script path или другом признаке. Он не доказывает точную версию, наличие CVE или владельца компонента.

узнать службы, работающие на web-сайте:
```
whatweb {URL}
```
или
```
whatweb {IP}:{port}
```

## Рабочая интерпретация

Сохраняйте URL, время, redirect chain, итоговый ответ и версию WhatWeb. Подтверждайте важный fingerprint независимым признаком и учитывайте CDN, reverse proxy, кастомные error pages и намеренное изменение заголовков.

## На собеседовании

1. Что такое fingerprint и почему он может ошибаться?
2. Почему заголовок `Server` не доказывает версию backend?
3. Чем технологическое обнаружение отличается от поиска уязвимости?

## Внешняя практика

На веб-цели внешней платформы сравните fingerprint WhatWeb с ручным HTTP-ответом и исходным HTML. Отметьте подтверждённые и предположительные технологии отдельно.
